## 二、口径：两层，不含混

- **我方不拼接**：11 段一律整段 `loop`，未裁切、未混音、未首尾相接、未转码、未把碎片映射成
  `cast|角色|情绪` 键。`BUILTIN_VOICE_PACK` 标 `mode:"bed" / noCut:true / intact:true`。
  R37 那种「26 个源裁成 2.4 秒再拼情绪包」的做法已彻底撤除。
- **上游处理如实标注**：AmbientSounds 为分钟级无缝循环；fspecii 上游做了 −16~−20 LUFS 归一化、
  96 kHz M4A 编码并标为无缝循环（README 未声明裁切）；still-sounds README 明载
  30–90 秒 `cut its most even minute`、首尾交叉淡化、−23 LUFS、Opus 重编码。
  这些是**上游**处理，不是「原始未裁切」，也不由我方再做拼接。

## 五、关键结论（不变）

公开 CC0 / PD 库能合法提供**环境音、无语义人声、拟音、音乐**；
「骆寒·冷/怒/收剑」这类**带具体台词的中文古风角色配音没有对应物**。
因此本语音包是：**真实公开的 CC0 录音 + 按关整段循环的氛围床音**，
台词仍由系统 TTS 分句扮演，**不是真人表演级配音**。
要真人配音，按 `设置 → 朗读 → 导入语音包` 载入 JSON（`mode:"speech"`，命中即替代 TTS）。

**元宝直接打开时的取舍**：单文件 HTML 内嵌 `rain_rooftop`（75 s 秋雨）1 段，
保证打开就有真实 CC0 音源；其余 10 段在包内 `voice/cc0full/` 按相对路径加载，
同目录解压后自动可用，缺失时 `Audio` 的 `error` 监听静默跳过、不报错不阻断。
**兼容边界**：部分 iOS Safari 不支持 Ogg，`Audio.play()` 静默失败、TTS 台词照常；
本轮新增 3 段 M4A/AAC 对该平台更友好。

## 六、发布前合规动作

1. CC0 无需署名；仍建议在「关于／鸣谢」写一行所用仓库与许可。
2. 逐文件记录仓库、路径、许可、时长、字节、SHA1 → `voice/cc0full/_台账.json`（11 段）。
3. 若改用 CC-BY 源，必须在游戏内列出作者与许可链接。
4. **不得**把完整录音裁成碎片再映射成「角色情绪」——R37 已撤的做法。
5. 保留源仓库许可页快照作授权凭证。
6. 引用 still-sounds 时须说明「上游已做无缝循环处理」，不得声称原始未裁切。
7. 引用 fspecii 时须说明「上游已归一化并以 M4A 编码」，不得声称原始未处理。

### 修掉的跨端真 bug

此前内嵌 1 段是 Ogg；部分 iOS Safari 不支持 Ogg/Vorbis，`Audio.play()` 静默失败，
前几轮只写进「已知边界」没修。R41 改为：

1. 内嵌段换成 **AAC/M4A**（iOS 与桌面都能播）；
2. 新增 `audioCan()` / `audioFmtOk()`，按 `HTMLMediaElement.canPlayType` 判定容器；
3. `levelBedClip()` 只从**当前浏览器可播的整段文件**里按关取模，Ogg 不可播时只选 M4A/AAC；
4. `startBed()` 再加一层预检，导入语音包也受同样保护。

真浏览器里 stub 掉 Ogg 后抽 12 关，返回值全部为 M4A/AAC 或内嵌 MP4；
`mode:"bed"` 叠加在系统 TTS 分句扮演之下，**不是拼接、也不是真人配音**。
