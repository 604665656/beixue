## 按一致性生成规格（以后每批照此执行）

1. `dst_intent=Image2Image`，`input_images=[{type:sandbox, value:/data/workspace/anim4/_style_ref.png}]`，`seed=3`，`image_ratio=1:1`。**禁用纯文生图出角色**。
2. prompt 结构固定为「只改两处：①背景换纯品红平涂；②本次要改的表情／动作／道具」＋固定约束块：

> 其余全部与第一张图完全一致：灰白蓬松绒毛、圆润二头身、蓝色大眼睛、黑色粗圆框眼镜、粉色内耳、只有一条蓬松大尾巴（绝不能有第二条）、柔和毛笔质感的绒毛边缘、平涂薄涂风格、细软线条，不要改成尖耳或赛璐璐硬阴影。角色实心封闭、身体与胳膊腿之间不留镂空缝隙、镜片反光用不透明浅灰白、角色身上不得出现任何品红像素。画面内不要任何文字、水印或标志。

3. 出图后跑 `python 角色一致性检查.py <新目录>`；判「不一致／偏离」的**重画**，不接入。
4. 通过后统一走色相键控 → 填实孔洞 → 去色溢 → 清右下水印 → 480px WebP q78，再接进 ART/CAST。
5. 旧批带场景整图只归档，不重抠、不混用。
