## 难度曲线：两条正交的轴

- **内容轴是波形，不是斜坡**：E 认人 → A 只听 → B **推翻上一关刚信的东西**（第一峰）→ D 回血 → C 换脑力 → F 多焦点（第二峰）→ G/H/I 起为高而平的考据平台 → 卷二到卷七按「章句／人事／武学／世道／改编／补遗」换认知类型，不靠加题量加码。峰后必谷：B 后接纯记忆的 D，F 后接单选的 G。
- **A、B 故意不提前讲透**：「第一遍必然被弃银骗到」是教学本身，失败即内容，不用新手提示抹平。
- **系统轴做矩阵**：模式管脚手架，难度管判定，两者正交。新手＋校勘不冲突——一边逐幕喂引导，一边题库最全；挑战＋浅读也不冲突。
- **动态升降档**：`STREAK` 记录连败／连满星；连两关 1 星给「降浅读／切新手」两个出口，连三关满星给「升一档」按钮，都不替玩家做决定。
- **失败不计入曲线**：漫游不写星、不解锁，但资料照样能翻。

## 三档难度（与模式正交）

| | ◔ 浅读 | ◑ 通读（默认） | ● 校勘 |
|---|---|---|---|
| 出题范围 | 仅 tier 1 基础题 | tier 1–2 | **全题库含 tier 3 考据题** |
| 第七关起各关题量 | 各 3 题 | 各 6–7 题 | 各 10 题 |
| 三星阈值 | 答对 ≥80% | ≥90% | ≥95% |
| 挑战容错 | 2 次失误 | 1 次 | **0 次** |

难度只改「题库深度与判定」，不改主链、结局分支与文案；大厅三卡、header 徽章浮层、各关 intro 三处都能切。第七关起建议先切校勘再进，否则考据题根本不出现。

## 档案逐步解锁

- 页签：**哈士喵设定（无条件）** + 序·读法（无条件）→ 人物谱系（E）→ 时间轴（A）→ 地理（B）→ 真词笺（D）→ 番外（C）→ 电影（F）→ **版本年表（G）→ 辕门簿（H）→ 改编对照（I）→ 章句卷（J）→ 人物卷（M）→ 武学卷（P）→ 世道卷（R）→ 改编卷（U）→ 补遗卷（W）** → 待补（二十四关全通）。
- 未解锁页签带 🔒，点进去给一张锁定卡：写清需要哪一关，并给「去走这一关」按钮直接跳。
- 后九页是按公开资料逐轮补的，正文里逐段标了来源性质（出版社书目／杂志史专文／正版梗概／转载章节／影视定档稿），异文一律并列存疑；卷页由卷内任一关开启。
- 通关结算页会写一行「🔓 已解锁档案《…》」；已开的页不会重新锁上。
- 漫游模式只逛不判定，因此不写星、不解锁；想开资料页切到新手／普通／挑战再走一遍对应关卡即可。

## 四种游戏模式（二十四关通用）

| | 新手 ◈ | 普通 ◇ | 挑战 ⚡ | 漫游 ❖ |
|---|---|---|---|---|
| 引导／回执 | 逐幕引导 + 选完停一屏 | 无 | 无 | 无 |
| 追问 / 提示 | 不限 | 4 次 / 1 次 | **0 次 / 0 次** | 不限 |
| 结算 | 结论 + 逐幕复盘 | 只给结论 | 结论 + **S/A/B/C 评级** | **不结算、不写星** |
| 特殊 | B 标建议动作、D 给方向、C 给关卡提示 | — | 答错记失误，星级更严 | A 前后翻幕不做断定；D 可跳题；E 不贴「最像谁」 |

- 挑战评级：`S` 零失误 / `A` 1 次 / `B` 2 次 / `C` 3 次以上。失误来源：A 断定答错、B 失镖、D 答错、F 判错、C 数值归零、G/H/I 判错。星级另按 `challengeAllowance()` 随难度收紧。
- 漫游是「只逛不被判定」：A 每幕给上一幕／下一幕／幕号直跳，读完整夜不进断定；D 给题号跳转、答完只看解释；E 只说「这一轮的落点」。
- 模式只作用于表现层，主链、数值、结局判定不变；难度才动题库与阈值。大厅双卡＋三卡、header 徽章浮层、各关 intro 都能切换。

## 第一关 · 人格测试（E）

12 道情境题都从原著处境里长出来：被传成不是自己的人、必败的仗、还不清的债、过了江就不能再过的线。每题 4 个选项，分别给两个角色加权（+2/+1）；12 题累计最高分落到八个角色之一：

骆寒 / 易敛 / 沈放 / 荆三娘 / 袁辰龙 / 萧如 / 耿苍怀 / 秦稳。

结果给：一句判词、三行「你的侠是哪一种」、最该先读哪一部、一句原著气质，再加**第二落点**作「另一面」对照。

**边界**：这是文学趣味映射，不是心理测评或诊断，不定义你是谁，不据此推断现实经历、能力或关系；不收集姓名、生日、职业等任何个人资料。漫游模式进一步去掉「你最像谁」的措辞。结果页保留明确说明。

## 第六关 · 谣言审判（F）

（第一关是人格测试；此处为最后一关。）

6 桩公案，每桩摆出 3 条同一件事的转述，问一个最稳的读法：七里铺把两桩并成一桩、弃银的「于心不忍」、六车与另一车、长桥题词归属分歧、袁老大死讯误判、一瓢酒店那张纸。答完立刻给「为什么稳」。考的正是全书核心——**别站回上帝视角**。

## 交互与技术

- 单 HTML，无外部依赖、无网络请求；事件委托挂在 `document.body`。
- `MODE` 四态、`DIFF` 三态全局；`askLimit()` / `hintLimit()` / `showGuide()` / `showPause()` / `showRec()` 下发模式差异，`tierMax()` / `quizFor()` / `starThresholds()` / `challengeAllowance()` 下发难度差异。
- `PROG` 存星级、通关标记与结局备注；`LAST` 记住上次玩的关；`archUnlocked()` 由 `PROG` 推导每页档案开合；`BGM` / `SFX` 各自持久化。
- 移动端优先：卡片单列、导航横滑、触控尺寸；420px 宽实际渲染验证。
- 关系图缩放用 inline `style.width` 覆盖 CSS `width:100%`，`ResizeObserver` + `postMessage` 同步 iframe 高度；父页监听 `bx-read-h`。
- 无头浏览器实测：四种模式 × 三档难度各走通二十四关；两路音控独立、难度过滤题量正确（3/6/10）、前六关联动与前三关 2 星上限、三种题型（单选／排序／归类）判定、升降档出口、漫游不写星也不解锁、档案逐关解锁与锁定卡、拆读站缩放与高度同步均正常。

## 朗读、语音控制与视障友好

### 四路开关，互不串扰

| 开关 | 默认 | 持久化 | 作用 |
|---|---|---|---|
| ♫ 背景音 | 关 | 是 | 关 → 雨声 → 琴音＋雨声，Web Audio 实时合成 |
| ♪ 音效 | 关 | 是 | 选项点击的极轻拨弦 |
| 🔊 朗读 | **关** | **否** | 朗读当前屏正文；不持久化，每次打开都是关 |
| 🎙 语音 | **关** | **否** | 语音命令；不持久化，需显式开启并授权麦克风 |

朗读与语音都由 header 按钮和「◐ 无障碍」面板双入口控制；关闭背景音不影响音效，关闭音效也不影响背景音，四路状态分别存、分别显示。

### 朗读模式（TTS）

- 基于 `speechSynthesis`，优先选中文语音（`zh-CN`），语速 0.8 / 1.0 / 1.2 三档。
- 开启后朗读当前屏主要文字（取 `#app` 文本，去空白、限 700 字）；`R` 键或「🔁 重读本屏」可随时重读。
- 「自动跟屏」默认开：翻到新一屏稍候自动读；关掉后只在主动重读/焦点朗读时发声。
- `⏸ 暂停 / ▶ 继续 / ⏹ 停止`、`Esc` 停止朗读；朗读开启时 `Tab` 到哪读到哪（焦点文本跟随朗读）。
- 不支持语音合成的浏览器会明确提示并保持关闭，不假装成功。

### 语音控制（ASR）

- 基于 `SpeechRecognition`（Chrome / Edge 系），中文识别，连续监听；不支持或权限被拒时给出状态说明，键盘与点按完全可用。
- 命令表：`开始 / 出发`、`下一题 / 继续`、`选一～选四`、`回大厅 / 返回`、`朗读开 / 朗读关 / 重读 / 停止朗读`、`背景音 / 音效 / 高对比 / 大字 / 帮助`。
- 本地 `file://` 下部分浏览器会限制语音服务；说明里写明可改用本地 http 服务打开，不虚构能力。

### 视障友好

- `<html lang="zh-CN">`、跳到主内容链接、`role="status" aria-live="polite"` 播报区：切关、判准、开锁都播报。

## 哈士喵 · 分层资产与换装台

> 作者授权角色形象的**主题/服装版本**，不是原著插图，也不是影视定妆。

### 为什么改分层

上一版是「一个角色 = 一张带场景的整图」：16 套就 16 张 1536px 厚重底图，想换个背景得整张重画，HTML 也因此涨到 3.5 MB。这一版拆成**背景层 + 角色层**，角色从背景里抠出来带 alpha，同一张背景下点谁就换谁。

### 资产构成

| 层 | 数量 | 格式／尺寸 | 说明 |
|---|---|---|---|
| 场景背景板 | 4 | JPEG 640px，约 217 KB | 雨驿雨夜／淮上夜帐／辕门月夜／秦淮灯影；统一厚涂笔触、暖灰纸纹、低对比、中央留空，**画里没有任何角色**，可反复复用 |
| 透明角色层 | 23 | WebP alpha 480px，约 623 KB | 本色 + 22 套 COS，`data:image/webp;base64` 内嵌，断网可见 |
| 旧整图归档 | 16 | JPEG 720px | 只在压缩包里作「原场景卡」，**不再内嵌** |

**减重**：内嵌美术从约 1.88 MB 降到约 1.14 MB，HTML 从 3553 KB → **1954 KB（−45%）**；压缩包里的 1024 整图也统一降为 720。更关键的是**以后每加一个人物只需一张透明层，不再多存一整张场景**。

### 抠图重做：旧图归档，新图专用

上一版把**带场景整图**硬抠，浅色绒毛、镜片、衣缝总被当成背景挖出洞，边缘还带一圈原场景残影。用户要求「之前有背景的留存做资产，另外生成可以抠图的」，于是分两路：

- **旧整图全部原样归档**（压缩包「美术归档／」），一张不删，作为原始美术资产保留，**不再参与站内抠图**。
- **另起一套「可抠图专用源图」**，分两轮共重画 **20 张**：
  - 背景是**单一纯品红／洋红平涂，不是绿幕**，四角同色、无渐变无投影；
  - 生成时强制角色轮廓**完全封闭、实心**，不画镂空、半透明纱、透空指缝腿缝，道具紧贴身体；
  - **角色身上不得出现任何品红像素**，镜片反光改为不透明浅灰白；
  - 这样色键之后角色体内不会被挖出需要填补的洞，也不留绿幕残色。

**后处理三道**（全部 23 层实测内部孔洞数为 0）：

1. **色相键控**：按 `R高 / B高 / G明显低` 判品红系，对渐变玫红也成立；软边由连续距离给出。

3. **去色溢（despill）**：模型偶尔仍在道具／衣袖上画一小块品红，只修**角色 alpha 内部**的品红像素（inpaint），背景品红由 alpha 裁掉；紫荆花等淡紫装饰因 G 值不够低被保留，不误伤。

## 横屏、面板与交互反馈

只做竖屏验收会漏掉一半设备。横屏实测（900×420 / 844×390 / 740×360）：设置面板 846px 高、超出视口 629–679px、`overflow:visible`、无关闭按钮——「点开了关不掉」由此坐实；舞台 857×280 被压成 3:1；header 117px 占 333px 视口的 35%。

**面板**：改四张卡片（声音／朗读／视觉／语音），一屏 2–9 个按钮；`✕ 关闭` + 点面板外 + Esc + 再点开关四种关法；`max-height:calc(100dvh-92px)` + `overflow-y:auto`。实测横屏面板高 229–259px，完整在视口内。

**横屏布局**：`orientation:landscape and max-height:560px` 下 header 压到 41px 单行、副标题隐藏、按钮横滑；舞台固定 `clamp(132px,30vh,200px)`、角色按高缩放 ×1.22；大厅双栏、猫图限高 170px、关卡地图三列、模式四列、难度三列；面板加宽到 `min(420px,100vw-24px)`。三档宽度实测无横向溢出。

**反馈与表演**：点选 190ms 朱砂脉冲；答对 `stage.ok` 点头动画 + 上行拨弦，答错 `stage.no` 摇头 + 沈放错愕脸 + 下行拨弦，2.6s 复原；`setMood` 现在直接刷新舞台角色层而不只改大厅头像。场景板淡入 + 12s 缓慢推镜，角色每幕滑入；`减少动效` 全关，`高对比` 下脉冲改纯黑描边。

**场景音**：`SCENE_SOUND` 把 11 张背景板映射到滤波频率／Q／增益／名称，`startScene(bg)` 建一次噪声链，`retuneScene(bg)` 换关时平滑改参数不重启。header 标签从「♫ 背景·雨」改为显示当前音景名（如「♫ 渡口水声」）。三态：关 → 随场景 → 音景＋琴。仍是实时合成、无音频文件、默认关、与另三路独立。

**场景复用**：`stageBlock` 拆出 `.stagebg` 独立背景层，按 `关+幕` 哈希取 3 种 `background-position` + 色温滤镜，11 板用出 33 种取景；滤镜不影响 `.stagecut`。24 关全通、三套皮肤、四路开关默认态、无障碍三开关在横竖屏都回归过。

## AVG 演出层

用户指出「图在上、白卡文字在下」不像 AVG。改为**整屏即画面**：`applyAVG()` 在 `render()` 末尾把 `.stage` 与其后的本屏正文包进 `.avgframe`，舞台 `position:absolute;inset:0` 铺底，正文块半透明宣纸气泡（带尖角、blur），选项同在气泡内；左上角说话人名牌随幕换角色。只移动 DOM、不复制文字，朗读 `innerText` 与 body 事件委托都不受影响；`AVGON` 可在「视觉」卡关闭，回到旧版布局。

**天气映射**：11 张背景板 → 6 类 FX（`rain/snow/sun/birds/dust/wind/night`）+ 5 类环境音（`rain/birds/wind/quiet/night`）。FX 全为 CSS 动画＋内嵌 SVG 鸟剪影：双层斜雨＋水花、两层雪片、光柱＋径向光斑漂移、三只鸟沿弧线飞、芦苇摇、窗光浮尘、旗影摆动、灯火闪烁。`减少动效` 全停，`高对比` 隐藏天气层并把气泡改纯白底黑字。

**环境音**：`chirp()` 用 sine 滑音 2–4 声一组（1750–2450Hz，45ms 上扬再回落），`cricket()` 4200Hz 短点，`pageRustle()` 带通噪声脉冲，`farThunder()` 58→34Hz 低频；`scheduleAmbient()` 按类型随机间隔递归调度，`startAmbient()` 切场景先 `stopAmbient()` 再起，避免叠声。只有 `BGM>0` 才播，**默认关、不持久化、无音频文件**。header 标签改为显示当前音景＋天气音名（如「♫ 驿道秋雨·远雷」）。

横竖屏都验过：气泡首块 `margin-top` 竖屏 `clamp(190px,34vh,300px)`、横屏 `clamp(126px,30vh,190px)`，角色层左侧不遮文字；24 关全通、四路开关默认态、三套皮肤、无障碍三开关均回归。

## 横屏按钮

之前只有 `@media (orientation:landscape) and (max-height:560px)` 自动适配，页面上没有可点的横屏控件。现于 `.hctl` 首位加常驻按钮（`position:sticky;left:0`，横屏横向滚动也不会滑走），四种状态：竖屏未开 `⛶ 横屏`／竖屏已开 `⛶ 退出横屏`／物理横屏未开 `▭ 横屏中`／物理横屏已开 `⛶ 退出横屏`。

点击 `enterLand()`：`LAND=1`、`FORCE=1`、给 `<html>` 加 `force-landscape`、尝试 `requestFullscreen()` 与 `screen.orientation.lock('landscape')`（失败静默，不影响版式这条退路）；竖屏弹引导条（版式开／关、知道了、退出），物理横屏不弹以免遮挡。`exitLand()` 清 `LAND/FORCE/class`、退全屏、unlock；设备仍横屏时播报「版式由系统方向自动决定」，避免用户误以为退出没生效。

**force CSS**：用括号配平解析三条横屏媒体查询，把其中 40 条规则的选择器统一加 `html.force-landscape ` 前缀复刻一遍，放在样式表末尾保证权重；再在 `@media(max-width:560px)` 补丁里把关卡地图／模式／难度改回两列、大厅改回单栏、`h1` 不换行、`.hctl` 改 `flex-start`，并给引导条做紧凑排版。竖屏不转手机也能看到完整横屏版式，且无横向溢出。

**状态**：不持久化（每次打开默认竖屏），`aria-pressed` 与 `aria-live` 同步；`matchMedia` 监听方向变化，重新同步按钮文案与引导条显隐。四种物理/模式组合在 420×900、900×420、844×390、740×360 实测：按钮始终在视口内、滚动到底仍可见、进入/退出/版式开关/收起全部可达，24 关全通不受影响。

## 真横屏 · 简洁化 · 素材登记

**真横屏**：之前「横屏按钮」只是套紧凑版式，竖屏用户看到的仍是竖向单栏，反馈「并没有横屏」。现改为竖屏设备点按钮后给 `<html>` 加 `rot-landscape`，把整个 `body` 用 `position:fixed; width:100dvh; height:100dvw; transform:rotate(90deg) translateY(-100%)` 转 90°，局部坐标即用户横拿手机时的正常横向坐标；`body` 成为滚动容器，`fixed` 面板与引导条随之旋转。设备自己横过来时 `matchMedia` 撤销旋转，避免二次转歪；回竖屏自动转回来。引导条可「把画面横过来 / 点还原」切换，退出时清干净。竖屏实测 `body` 813×500、`matrix(0,1,-1,0,500,0)`、关卡地图三列、模式四列。

**简洁化**：气泡 `.70` 透明 + 7px 模糊（夜雨 `.68`），名牌与解释块同步减重；大厅四条 pill 收成两条、`quote` 改细线淡色、`sig` 收一行、`inkdiv`／长说明收进 `<details>`；E 关去掉重复的「新手模式」标签；`applyAVG` 把进度条与空占位并进上一块，不再出现截图里那种孤立空白米白条；选项文字由蓝改墨色。

**动画素材登记**：新增档案页「动画素材登记」与两份导出（MD / CSV），共 **54 项**全部标「待生成」，按 5 类 × 6 批：天气粒子 12、角色表情 14、角色动作 14、场景板 8、序列帧 6。每项写明用途、当前 CSS/SVG 替代、优先级与生成规格（纯品红底实心封闭、场景板空场景同 seed、渐变素材不抠图）。这是登记簿而非完成清单：做一批改一批状态，未做的保持原样，不虚构进度。

## 呼吸感 · 敬请期待 · 人声表演

**呼吸感**：`@keyframes catIn` 改为只动 opacity，`catBreathe` 只动 transform（4.4s，translateY -2.2px + scaleY 1→1.016），两条 animation 并列不抢属性；反馈动画 `catNod/catShake` 仍可整条覆盖。设置「视觉 → ◈ 角色呼吸」可关，`减少动效`／`高对比` 自动停。明确说明这是**整层起伏**，头/耳/尾不能单独动；真呼吸要拆身体/头/耳/尾四层并出吸气呼气帧，已登记为批次 6 的 6 项。

**表演未完成的关卡**：新增 `DATA.perf`（24 关各自 `need` 类别 + 空 `done`）。默认 `基础优先`：可玩，但关卡卡与舞台名牌标「演出筹备中 · 敬请期待」；大厅有完成度条与一键切换。切到 `仅完整演出`：`go` 事件真拦截，进入 `coming` 页，列出该关缺哪几类、对应批次，只给「切回基础优先并进入 / 回大厅」两个出口——锁是实的，不拿半成品冒充完成。补素材时把 `PERF_DONE['关|类别']` 置 1 即自动解锁。

**人声能不能表演**：能，但要分清三层。① 系统 TTS 按角色改 `pitch/rate`（骆寒 .78、沈放 1.14、朱妍 1.22…），`分句扮演` 把整屏按句切开、引号内台词用角色声线、叙述用旁白——**离线零素材，但只是声线区分不是表演**，且受系统中文语音数量限制。② 外部导入 JSON 语音包（`clips` 键为 `关卡:幕` 或 `cast|角色ID`，值音频 data URI），命中即 `new Audio().play()`、未命中回退 TTS；**只存会话内不写进 HTML**，因为音频 base64 会撑爆单文件且真人录音需授权。③ 云端 TTS 与 wasm 引擎不做：前者要联网+密钥，后者几十 MB，都破坏离线单文件。设置「朗读」卡含开关、试听、导入、移除与格式说明。

**登记簿扩充**：54 → **70 项**（新增「呼吸分层」6 项、「语音包」10 组），类目 7 类、批次 2–7，全部标「待生成」。档案页补了呼吸与 voice 的原理/边界说明、逐关完成度折叠表。MD/CSV 同步导出。
