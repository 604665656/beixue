# 杯雪游戏总站

《杯雪》同人互动游戏：二十四关 · 七卷 · 四模式 · 三档难度 · 单文件离线可玩。
角色是一只灰白绒毛猫（哈士喵），同一套画风贯穿立绘、表情层与逐帧动画。

**当前进度：184 个表情格中 147 格是专属生成层（146 格接入生效），37 格复用同角色已过检层。**
按现有节奏还需 4 轮（每轮 10 张）可做到全部专属。

---

## 快速开始

直接双击 `game/index.html`。单文件、零外链、零音频、无需联网、无需构建。

支持手机竖屏／横屏与桌面三种尺寸，界面随尺寸重排，无横向溢出。

## ⚠ 已知问题（务必先读）

### 1. 点击／拖动立绘**没有表演**
立绘命中区 `#app .sprhit` 能收到指针事件，但**没有绑定**：实测轻点、拖动、长按三种操作后，
`.sprhit` 内部**不产生 `.sprite` 元素**，也不派发 `sprperf` 事件，名牌文字与画面均不变。

点击**选项**会触发表演（换表情层＋点头／摇头＋名牌跟随说话人），这部分正常。

要让点击和拖动有 AVG 式演出，需要新写这块交互：`sprPerfRun(kind, dir)` 函数已存在且可调用
（`window.__sprPerfRun`），缺的是从 `.sprhit` 的 pointer 事件到它的接线，以及立绘元素本身的渲染挂载。

### 2. 本站依赖 `PROC_ART`，已在 `game/index.html` 修复
表情谱系构建处原写作 `gen:PROC_ART.has(art) ? ... : ...`，而 `PROC_ART` 定义在文件后段，
触发 TDZ 报错 `PROC_ART is not defined`，导致整页脚本中断。已改为
`(typeof PROC_ART!=='undefined' && PROC_ART.has(art)) ? ... : ...`。

修复后在 Chromium 实测：竖屏 420×900、横屏 900×420 **均为 0 运行时错误**，
`EXPR_SPECIAL=147`、谱系 184 格（专属 146／复用 38）正常建立，160 个按钮可点，无横向溢出。

`history/` 里保留了修复前版本与零报错基线版本，可对照。

### 3. 轻量版本次不可用
`杯雪游戏总站_轻量版.html` 与主站当前**字节完全相同**（压缩步骤未生效），体积同为约 19 MB，
不是真正的轻量版。本仓库未收录，请勿使用。

### 4. 美术一致性：角色层无离群，离群集中在背景／特效
全量 500 张图逐张比对 7 项指标（色温、墨色深浅、灰调占比、鲜色占比、色相离散、轮廓疏密、抠图边缘）：
- **角色层 0 层离群**，同角色前后色温跨度均在阈值内；
- 偏色离群的约 81 张全部是背景图与天气／灯火特效，属预期表现；
- R64 那批（庚不信／文翰林／金和尚／焦泗隐等 7 张）相对**早期**角色图明显偏暖偏艳（跨度 31–44），
  与同角色的**新**图之间则很接近（≤10.1）。早期图本身偏灰是主因，这批仍建议后续调色统一。

### 5. 素材缺口
- 短须、浅疤（朱妍颊疤、秦稳八字须等）在多轮生成中始终未落实；
- R49／R50 共 19–20 张程序化本体重绘待 AI 重画（当前谱系已不含全部，实际待重画数以运行时 `PROC_ART` 为准）；
- 动画仍是「逐张画好再按顺序合成」，非真正逐帧驱动；
- 语音包已按需求方要求撤除，仓库内**音频文件为 0**，仅保留许可清单。

## 美术口径

- 底色：纯品红键控；R58 起 AI 出图底色变淡，改用**从画面边缘向内泛洪**识别背景，避免误抠猫身浅色；
- 水印：AI 出图右下角「元宝 AI 生成」在**抠图前的原图层**按连通域预清除，非成品覆盖；
- 不使用透明贴片叠加、切片拼接、GIF 拼接冒充新立绘；每张表情层都是独立生成的整帧；
- 角色行头、须发、饰物与身体须**同一笔触连续生长**，禁止独立配件「扣上去」。
